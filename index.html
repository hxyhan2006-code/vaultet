Gemini API Key
Gemini API Key ยังไม่ได้ตั้งค่า

ใส่ได้สูงสุด 10 คีย์ — ถ้าคีย์แรกโควต้าเต็ม (429) ระบบจะสลับไปใช้คีย์ถัดไปให้อัตโนมัติ Key จะถูกเก็บไว้ในเครื่องนี้เท่านั้น (localStorage) ไม่ถูกส่งไปรวมในไฟล์สำรองข้อมูล และไม่ถูกอัปโหลดไปที่ไหนนอกจากตอนเรียก AI

OpenRouter (AI หลายค่าย)
สถานะ ยังไม่ได้ตั้งค่า

ทุกงาน AI ใช้ Gemini ฟรีก่อน ถ้าโควต้าฟรีเต็มทุกคีย์ ระบบจะสลับมาใช้ OpenRouter เองเบื้องหลัง (ไม่แจ้ง) คีย์เก็บในเครื่องนี้เท่านั้น ไม่รวมในไฟล์สำรองข้อมูล

เพดานในแอป ถึงแล้วแอปจะไม่สลับไปใช้ OpenRouter อีก กันการใช้เพลินได้ แต่ไม่กันกรณีคีย์หลุด ลิมิตแข็งจริงคือเครดิตที่เติมไว้ และวงเงินของคีย์ในเว็บ OpenRouter
