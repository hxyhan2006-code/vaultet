# ชุดทดสอบ Vaultet

ทดสอบด้วยเบราว์เซอร์จริง (Chromium) ที่จอกว้าง 380px กับข้อมูลสมมติ ไม่แตะข้อมูลจริง ไม่เรียก API ภายนอก
ครอบคลุมหน้าหลัก แท็บทั้งหมด ฟอร์มเพิ่ม/แก้รายการ หนี้ บัญชี เงินกันไว้ เงินให้ยืม ค่าใช้จ่ายประจำ เป้าหมาย ล็อกแอป
กล่องข้อความในแอป โหมดบัญชีเดียว และข้อมูลที่ส่งให้ AI

## รัน

```
npm install
npx playwright install chromium
npm test
```

GitHub รันชุดนี้อัตโนมัติทุกครั้งที่ push (ดูแท็บ Actions → "tests") ถ้ามีอะไรพังจะเป็นกากบาทแดง

## กติกาเวลาเพิ่มฟีเจอร์
- ถ้าแก้พฤติกรรมที่มีทดสอบอยู่ ให้แก้ไฟล์ทดสอบให้ตรง และห้ามปิดหรือข้ามข้อที่ล้มเหลวเพื่อให้ผ่าน
- ทุกไฟล์พิมพ์ `PASS ...`/`FAIL ...` ต่อข้อ และจบด้วย `no js errors` ถ้าไม่มี error ใน JS ของหน้าเว็บ
- ไฟล์ `tlib.js` มีตัวช่วยกดกล่องข้อความในแอป (`dlgOK`, `dlgCancel`, `dlgChoose`) และตัวเฝ้าดูว่ามีกล่องของเบราว์เซอร์โผล่ไหม (ต้องไม่มี)
